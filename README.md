# PaveDetail - Детали покрытий

Модуль для Топоматик Robur: строит чертежи узлов дорожной одежды по регионам
площадки - поперечный разрез со штриховками по материалам, нумерованные
выноски, экспликация. Плюс ведомость состава конструкций с выгрузкой в CSV и HTML.

**Разработчик:** Yaroslav I. Abramov

## Установка

Только через [AbrModules](https://github.com/Y-Abramov/abrmodules) (Библиотека модулей ABR).

## Команды

- **Узел** - построить узел по одному региону
- **Пакет** - построить узлы по всем уникальным конструкциям площадки
- **Ведомость** - таблица состава конструкций на план + CSV/HTML
- **Каталог** - правила штриховок материалов и типоразмеры бортов
